# Hostel Complaint Management System

A web-based application developed using Spring Boot to streamline the hostel complaint management process.

Students can register, log in, and submit maintenance complaints. Administrators can assign complaints to staff members, monitor their progress, and update complaint statuses. Staff members can view assigned complaints and mark them as resolved after completing the work.

## Features
- Student Registration & Login
- Secure Authentication using Spring Security
- Role-Based Access Control (Admin, Student, Staff)
- Complaint Creation and Tracking
- Complaint Assignment to Staff
- Status Updates (Pending, In Progress, Resolved)
- Admin Dashboard
- MySQL Database Integration
- Responsive UI with Thymeleaf

## Tech Stack
- Java
- Spring Boot
- Spring Security
- Spring Data JPA (Hibernate)
- Thymeleaf
- MySQL
- Maven
- Lombok
